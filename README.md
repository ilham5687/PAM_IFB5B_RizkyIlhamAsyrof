## Judul Proyek
Aplikasi Pengingat Tugas

## Deskripsi
Aplikasi Pengingat Tugas merupakan aplikasi sederhana yang digunakan untuk mencatat dan mengingatkan mahasiswa mengenai tugas-tugas yang harus dikerjakan. 
Aplikasi ini menampilkan informasi tugas, batas waktu pengumpulan, dan status tugas agar mahasiswa dapat mengatur tugas dengan lebih teratur.
